# Meditations of St. Thomas Aquinas, O.P. — For Every Day

A static website for browsing the complete text of **_Meditations of St. Thomas
Aquinas, O.P. for Every Day_**, adapted from the Latin of Father Mezard, O.P.
by **Father E. C. McEniry, O.P.** (College Book Company, Columbus, Ohio, 1941).

- **370 daily meditations** arranged for every day of the year
- **17 spiritual topics for retreats** and **11 prayers** of St. Thomas
- The default meditation matches **today's date on the traditional (1962)
  liturgical calendar** — Easter, Septuagesima, Lent, the Paschal and
  Pentecost seasons are computed for the current year
- Browse by **calendar day** (month grid, feast quick-jump, date picker) or by
  the **book's own order**, with search across all meditations
- Light ("parchment") and dark ("candlelit study") themes, fully responsive

## Develop

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint
```

The book content lives in `public/book.json` (generated by `work/extract.py`
from the 1941 scan); the lightweight index used by the UI is in
`src/data/index.ts`. The liturgical calendar logic is in `src/lib/liturgical.ts`.

## Deploy on Render.com

This site is fully static (`output: "export"`) and can be deployed as-is:

1. Push this repository to GitHub.
2. On [render.com](https://render.com) choose **New → Static Site** and connect
   the repository (or just use the included `render.yaml` blueprint via
   **New → Blueprint**).
3. Build command: `npm install --no-package-lock && npm run build`
   Publish directory: `out`

That's all — the site has no server, no database, and no environment
variables. Any other static host (Netlify, Cloudflare Pages, GitHub Pages)
works the same way.
